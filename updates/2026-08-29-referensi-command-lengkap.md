# Referensi command lengkap

Dokumentasi command MineHive kini dipusatkan di `DAFTAR_COMMAND.md`. Referensi tersebut mencakup format selector bot/class/global, seluruh command chat Minecraft beserta aliasnya, penggunaan Command Console dan viewer dashboard, command terminal, action bot melalui REST API, daftar endpoint operasional, contoh goal terstruktur, serta troubleshooting command.

Contoh dan batas parameter diselaraskan dengan parser command, koordinator fleet, CLI, dan route API yang aktif pada versi ini.
