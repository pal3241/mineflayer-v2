# 2026-08-30 - 0.7.2 Collection and Smelting Hardening

## Perbaikan

- Payload collection melalui Task Queue sekarang menggunakan `{ block, count, maxDistance }`, bukan field `item`.
- Smelting otomatis mengakuisisi input recipe dan fuel sebagai dependency sebelum menjalankan smelt.
- Formula smelting yang malformed atau self-referential ditolak agar tidak membuat recursive loop.
- Craft execution menggunakan target inventory kumulatif untuk request di atas 64 item.
- Regression test ditambahkan untuk collection payload, smelting input/fuel dependency, dan batch behavior.
